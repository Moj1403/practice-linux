# سامانه آزمون وب‌اپلیکیشن محلی لینوکس (Linux Web Exam)

این نسخه دارای رابط کاربری وب مدرن (دارک مود، انیمیشن، تایمر و نمودار پیشرفت) است که به‌صورت محلی روی سیستم لینوکس دانش‌آموز اجرا می‌شود.

---

### 🚀 نحوه اجرای دانش‌آموز

1. نصب نیازمندی‌ها (فقط کتابخانه Flask):
   ```bash
   pip install -r requirements.txt
   ```

2. اجرای وب‌اپلیکیشن:
   ```bash
   python3 app.py
   ```

3. مرورگر را باز کرده و به آدرس زیر بروید:
   ```
   http://127.0.0.1:5000
   ```

4. نام و کد ملی خود را وارد کرده و آزمون را شروع کنید.
5. تمرین‌ها را در ترمینال سیستم انجام دهید و با زدن دکمه «بررسی پاسخ روی سیستم»، بازخورد آنی بگیرید.
6. در پایان با دکمه «پایان آزمون»، کارنامه دیجیتال را دانلود کرده و برای استاد بفرستید.

---

### 👨‍🏫 نحوه اعتبارسنجی نمره توسط استاد

```bash
python3 verify_result.py exam_result_9912345.json
```
