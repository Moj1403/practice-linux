# 🐧 سامانه جامع آزمون عملی لینوکس (Linux Practical Exam Suite)

این سامانه برای برگزاری آزمون‌های مهارتی، کارگاهی و سناریومحور لینوکس طراحی شده است. دانش‌آموزان به دو روش **خط فرمان (CLI)** و **تحت وب (Web App)** می‌توانند مهارت‌های عملی لینوکسی خود را محک بزنند.

---

## 🚀 راهنمای سریع برای دانش‌آموزان (Quick Start)

### گام ۱: دریافت پروژه از گیت‌هاب
ترمینال لینوکس خود را باز کرده و دستور زیر را اجرا کنید:
```bash
git clone https://github.com/Moj1403/practice-linux.git
cd practice-linux
```

---

### گام ۲: انتخاب روش آزمون

#### 💻 روش اول: نسخه خط فرمان (CLI) — *توصیه‌شده (بدون نیاز به نصب هیچ برنامه‌ای)*
این نسخه به هیچ کتابخانه یا اینترنتی نیاز ندارد و مستقیماً روی هر لینوکسی اجرا می‌شود:
```bash
cd cli_exam
python3 exam.py
```
**نحوه کار در ترمینال:**
1. زبان آزمون (فارسی / انگلیسی) و سپس نام و **کد ملی** خود را وارد کنید.
2. سوالات را مطالعه کرده و دستورات لینوکسی (`cd`, `ls`, `mkdir`, `chmod`, ...) را مستقیماً درون خود برنامه اجرا کنید.
3. با زدن کلید **`c`** پاسخ شما در همان لحظه تست شده و امتیاز ثبت می‌شود.
4. با زدن کلید **`f`** آزمون پایان یافته و فایل کارنامه (`exam_result_<کدملی>.json`) تولید می‌شود.

---

#### 🌐 روش دوم: نسخه وب‌اپلیکیشن (Web Application)
اگر مایلید در محیط گرافیکی مرورگر با تایمر و نوار پیشرفت آزمون دهید:
```bash
cd web_exam
pip install -r requirements.txt
python3 app.py
```
سپس مرورگر خود را باز کرده و وارد آدرس زیر شوید:
👉 **`http://127.0.0.1:5000`**

---

## 📚 سرفصل‌ها و دسته‌بندی سؤالات آزمون

آزمون شامل **۱۲ سناریوی عملی** در ۶ دسته‌بندی موضوعی است:
1. **مدیریت فایل‌ها و پوشه‌ها:** دستورات `cp`, `mv`, `rm`, `ls`
2. **جستجو و فیلتر متون:** دستورات `head`, `tail`, `grep`, `diff`
3. **مجوزها و سطوح دسترسی:** دستورات `chmod`, دسترسی‌های `750` و `700`
4. **فشرده‌سازی و آرشیو:** کار با `tar`, `gzip`
5. **مدیریت پردازش‌ها:** دستورات `ps`, `kill`, `killall`
6. **شبکه و مستندات سیستم:** دستورات `man`, `ping`

---

## ⚠️ قوانین نمره‌دهی و راهنمایی (Hint Penalty)
* ارزش هر سؤال **۱۰ نمره** است.
* در صورت استفاده از بخش راهنمایی (Hint)، **۳ نمره جریمه** از سقف امتیاز آن سؤال کسر می‌گردد (قبل از نمایش، اخطار تاییدیه داده می‌شود).

---

## 👨‍🏫 راهنمای استاد: بررسی اصالت کارنامه و ضدتقلب
هر کارنامه دارای **امضای دیجیتال رمزنگاری‌شده (HMAC-SHA256)** است. برای بررسی کارنامه ارسالی دانش‌آموز:

```bash
python3 cli_exam/verify_result.py exam_result_0012345678.json
```
- **در صورت سلامت:** نمره، تعداد راهنماهای مصرفی و تاییدیه نمایش داده می‌شود.
- **در صورت هرگونه دستکاری دستی در فایل:** اخطار جعل و ابطال کارنامه ظاهر می‌شود.
