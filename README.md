# پلتفرم آزمون عملی لینوکس (Linux Practical Exam Suite)

این پروژه شامل دو نسخه آماده برای برگزاری آزمون‌های مهارتی، کارگاهی و سناریومحور لینوکس است:

1. **نسخه خط فرمان (CLI):** داخل پوشه `cli_exam/`  
   - کاملاً بی‌نیاز از هرگونه کتابخانه جانبی (Pure Python 3)
   - مناسب برای اجرا در محیط ترمینال سرورها، ماشین‌های مجازی یا سیستم‌های سبک
2. **نسخه وب‌اپلیکیشن (Web App):** داخل پوشه `web_exam/`  
   - طراحی مدرن با پالت دارک‌مود، تایمر زنده، نوار پیشرفت و فیدبک آنی
   - تحت فریم‌ورک سبک Flask

## 🛡️ سیستم جلوگیری از تقلب و جعل نمره (Digital Signature)
هر دو نسخه مجهز به سیستم امضای رمزنگاری‌شده (**HMAC-SHA256**) هستند:
- در پایان آزمون، یک فایل با نام `exam_result_<student_id>.json` تولید می‌شود.
- این فایل شامل مشخصات، نمره، سوالات حل‌شده و یک امضای دیجیتال است.
- اگر دانش‌آموز فایل نمره را باز کند و نمره خود را دستی تغییر دهد، استاد با اجرای `python3 verify_result.py <file>` بلافاصله هشدار جعل و ابطال کارنامه دریافت می‌کند.
- **تغییر کلید امنیتی:** می‌توانید متغیر `SECRET_SALT` را در فایل‌های پروژه به یک رشته اختصاصی برای کلاس خودتان تغییر دهید.

## ✏️ چگونگی افزودن یا ویرایش سوالات
در هر پوشه، فایل `questions.json` شامل ساختار زیر است:
```json
{
  "id": 1,
  "title": "عنوان سوال",
  "description": "صورت مسئله و توضیحات سناریو",
  "points": 15,
  "hint": "متن راهنمایی برای دانش‌آموز",
  "verify_cmd": "دستور بش لینوکس برای بررسی وضعیت (در صورت صحت با exit code 0 خارج شود)"
}
```
هر فرمانی که در لینوکس وضعیت خروج `0` برگرداند به معنی درستی پاسخ دانش‌آموز تلقی خواهد شد (مثلاً ترکیب `test`, `grep`, `stat`, `diff` و ...).
