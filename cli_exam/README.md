# سامانه آزمون خط فرمان لینوکس (Linux CLI Exam)

این ابزار برای آزمون‌های عملی و کارگاهی لینوکس طراحی شده است. دانش‌آموزان بدون نیاز به نصب هیچ‌گونه کتابخانه‌ای می‌توانند آن را مستقیماً اجرا کرده و آزمون دهند.

---

### 🚀 نحوه اجرای دانش‌آموز

1. وارد پوشه `cli_exam` شوید:
   ```bash
   cd cli_exam
   ```

2. برنامه را اجرا کنید:
   ```bash
   python3 exam.py
   ```

3. نام و مشخصات خود را وارد کنید.
4. صورت مسئله هر سؤال را بخوانید و کارهای خواسته شده را در یک تب/پنجره دیگر ترمینال انجام دهید.
5. کلید `c` را بزنید تا پاسخ شما بررسی و نمره ثبت شود.
6. در پایان با کلید `f` آزمون را پایان دهید؛ فایل کارنامه با نامی شبیه `exam_result_9912345.json` ساخته خواهد شد.

---

### 👨‍🏫 نحوه اعتبارسنجی نمره توسط استاد

برای اینکه مطمئن شوید دانش‌آموز فایل نمره را دستکاری نکرده است:
```bash
python3 verify_result.py exam_result_9912345.json
```
این دستور امضای دیجیتال (HMAC-SHA256) فایل را بررسی می‌کند و در صورت کوچکترین تغییر در نمره یا اطلاعات، اخطار جعل می‌دهد.
